THE BLACK BOOTS — VRFS WEBSITE (LOCAL DEMO)

HOW TO OPEN:
1. Extract this ZIP file.
2. Open the black-boots-website folder.
3. Double-click index.html to open the website in your browser.

FILES:
- index.html: website pages and forms
- style.css: dark esports styling
- script.js: navigation and demo features

IMPORTANT:
This is a front-end demo. Login is not real authentication, admin controls are not secure,
and tryout submissions are saved only in the browser being used. They are not sent to Discord
or shared with other visitors. Do not use this version to collect real passwords or private data.
